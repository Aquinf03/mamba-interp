\begin{center}
  {\Large\bfseries Abstract}
\end{center}

\begin{quote}
When AR-finetuned Mamba-130M does associative recall, the bind lives in
layer-17 recurrent state $\mathbf{h}$, not in the residual bus.
Zeroing that state on write collapses accuracy (AR $0.961 \to 0.297$ at
L17 alone; late-block wipe $0.242$).
Copying this example's L17 $\mathbf{h}$ restores $0.961$; copying the
L17 residual at the same sites stays at wipe.
Residual-matched write noise, budgeted to the mixer $\ell_2$ of the wipe
(write mean $29.6$), does nothing ($0.961$).
Linear probes and a small MLP find no value code at end-of-list;
residual probes win at the query because that is readout, not store.
Padding overwrites the store: a $\Delta \leftarrow 0$ clamp on pads helps
in sign across three seeds ($+0.08$ to $+0.27$).
Stuffing is a different failure (the same clamp hurts).
Swap of $\mathbf{h}$ breaks recall but does not copy the donor value
(donor accuracy $0.072$).
The code is distributed across $N=16$ and SVD rank; it is not a portable
key-value slot.
Limitations: 130M only; synthetic AR/ATR; the store is a task-finetune
algorithm (pretrained 130M and 370M are both $0\%$ on these splits);
pad magnitude is seed-sensitive. We run the unfused sequential scan.
\end{quote}

\section{Introduction}

Mamba stores context in a recurrent state $\mathbf{h}_t$, not in a
token-token attention matrix \cite{gu2023}:
\begin{equation}
  \mathbf{h}_t = \bar{\mathbf{A}}_t \mathbf{h}_{t-1} + \bar{\mathbf{B}}_t \mathbf{u}_t,
  \qquad
  \mathbf{y}_t = \mathbf{C}_t \mathbf{h}_t + D \cdot \mathbf{u}_t.
\end{equation}
Interpretability work on Mamba has mostly read it as a transformer:
implicit attention \cite{ali2025}, token maps \cite{pitorro2025}, residual
tracing and ROME-style edits \cite{sharma2024}, IOI circuits
\cite{ensign2024}.
Those are useful neighbors. They do not locate a bind inside $\mathbf{h}$.

A companion result is that \emph{pretrained} Mamba-130M raw state is
severely anisotropic and linearly uninformative as a frozen encoder
\cite{wagh2026}.
That is a null about frozen geometry.
It leaves open a different question: when the same backbone is made
competent at a memory task, where does the algorithm put the bind, and is
that object the residual bus?

We full-finetune \texttt{state-spaces/mamba-130m-hf} on synthetic
associative recall until eval AR is $0.961$, then intervene on
$\mathbf{h}$, $\mathbf{B}$, $\mathbf{C}$, $\Delta$, and the residual at
named token windows, with residual-matched noise as a control.
Held-out eval uses $n=128$ for AR/ATR and $n=64$ for length.
Two additional finetune seeds replicate the L17 wipe and the pad/stuff
sign.

The bind is not ``late residual'' and not ``all 24 layers.''
Write-zeroing $\mathbf{h}$ one layer at a time leaves almost every layer
at clean ($\approx 0.96$).
Only layer 17 collapses ($0.297$).
Putting this sequence's L17 $\mathbf{h}$ back after a late wipe fully
restores AR; putting L16 or L18 $\mathbf{h}$, or the actual L17 residual
skip, does not.
Probes at the query are readout.
We do not claim that pretrained Mamba already solves AR, that
$\mathbf{h}$ linearly beats residual at the query, or that $N$-slots are
a content-addressable cache.

\section{Setup}

\subsection{Model}
Base: \texttt{state-spaces/mamba-130m-hf} (24 layers, $d=768$, $E=1536$,
$N=16$).
Paper checkpoint: full FT, 800 steps, 2048 AR train, seed 1, lr
$3\times 10^{-4}$, AMP fp16 with FP32 master weights, eval AR $0.961$
(peak 2.66\,GB, 312\,s on an RTX 4070 Laptop, 8\,GB).
Hooks use the unfused sequential scan (no fused CUDA scan).
Pretrained 130M and pretrained 370M are both $0\%$ next-token AR, ATR,
length, and factual on the frozen splits.
All causal claims below are on the finetuned 130M checkpoint unless
labeled otherwise.
Replication runs (seeds 2 and 3) are not the paper checkpoint.

\subsection{Tasks}
\textbf{AR.} A list of key-value symbol pairs, then a query key; the
target is the bound value (4 pairs by default).
Symbols are single tokens under the GPT-NeoX tokenizer.
\textbf{ATR.} Associative treecall / induction:
$\ldots A\, B \ldots A \to B$ (short: 1 mark; mid: 2).
\textbf{Length.} In-range lists, OOD pad (32 tokens before the query),
and filler stuffing between pairs.
\textbf{Multi-query.} 4 pairs, 2 queries, on a separate held-out split.
\textbf{Factual.} Short subject-object prompts; diagnostic only.

Accuracy is greedy next-token match on the target id.
Confidence intervals are bootstrap over examples.

\subsection{Interventions}
Unless named, write-window ops hit late layers 16 to 23.
A state wipe zeros recurrent $\mathbf{h}$ on the window.
A restore pastes this example's clean L17 vector after a late wipe, at
last write, value, or query.
Residual-matched noise adds a random residual vector whose $\ell_2$
matches the mixer-output change from the write-window state wipe on the
same example.
A local-only run kills SSM recurrence and leaves conv $+\,D\cdot u$.

Late mixer identity ablation is $0\%$ (mean logprob $\approx -82$): late

That is not the same as ``memory lives in every late layer.''

The L17 store is already in place by finetune step 50 (clean $0.961$,

Later steps increase L17 dependence (wipe $0.352 \to 0.297$ at 800).
We did not catch a birth.
Pretrained AR is $0\%$, so this is a finetune algorithm, not an uncovered
pretrained circuit.
Scale does not unlock the synthetic bind: pretrained 370M is also $0\%$
on the same strings.

\section{Store is not readout}

Residual should win at the last layer last token: that is the bus the LM
head reads.

Finetuned, query token, $\approx$40-way: L23 residual test $0.929$ versus
best $\mathbf{h}$ $0.607$.
Pretrained: both near chance \cite{wagh2026}.

A separate AR probe set ($n=384$, seed 99, 52-way) is shown in
Figure~\ref{fig:probes}:
at $t=0$, nothing ($\approx 0.03$);
at the value token, residual is $1.000$ even at L0 (the letter is on the
bus);
at last write, residual $0.073$ and $\mathbf{h}$ $0.104$ (no linear value
code after the list);
at query L23, residual $0.979$ versus $\mathbf{h}$ $0.885$ (residual is
readout).

A two-layer ReLU MLP (256-d) at last write is still chance (test
$0.03$ to $0.06$; train $1.0$).
Superposition / key-addressing is not a linear-probe artifact.

\section{Layer-17 state is necessary}

Write-zero $\mathbf{h}$ on late layers: AR $0.242$
(CI $0.172$ to $0.320$).
Residual-matched write noise: $0.961$ ($\Delta$LP $\approx 0$).
Query residual noise: $0.883$ (real, small).
Zeroing $\mathbf{B}$ and clamping $\Delta$ on write are identical to
zeroing $\mathbf{h}$: no writes implies empty $\mathbf{h}$.
These are one block-write condition.
Zeroing $\mathbf{h}$ or $\mathbf{C}$ at the query, and the local-only
run, are $0\%$ with LP $\approx -50$: readout death, not the store
result.

Mixer $\ell_2$ of the write-window state wipe versus clean is not a tiny
budget: write mean $29.6$ (median $5.8$, p90 $85.5$); query mean $54.4$.
Residual-matched write noise still does nothing.

\begin{figure}[t]
  \centering
  \includegraphics[width=\linewidth]{fig2_layer_sweep.png}
  \caption{Zero $\mathbf{h}$ on write, one layer at a time, $n=128$ AR.
  Only L17 collapses ($0.297$). The store is not late residual and not
  all 24 layers.}
  \label{fig:sweep}

Almost every single-layer write-wipe stays at clean
(Figure~\ref{fig:sweep}).
Only L17 collapses: $0.297$ (CI $0.219$ to $0.383$).
L16 and L18 stay clean.
Full late-block $0.242$ is L17 plus a little extra.
Three FT seeds: L17 wipe $0.297$ / $0.289$ / $0.320$.
Not a one-run fluke.

\section{Layer-17 $\mathbf{h}$ is sufficient; residual is not}

Late wipe $0.242$; restore this sequence's L17 $\mathbf{h}$ at last write
$\to 0.961$ (CI $0.929$ to $0.992$).
Restore L16 $\mathbf{h}$: $0.258$; L18: $0.242$.
Sufficiency is L17, not any other late layer.

After the same late wipe, paste the actual clean L17 residual skip:
$0.242$ at last write, $0.258$ at query.
Residual-matched noise already missed; this is copy-the-real-vector.

Restore L17 $\mathbf{h}$ at the queried value token $0.969$, last write
$0.961$, query $0.953$.
The bind is in L17 $\mathbf{h}$ from write through readout, not a
last-write-only snapshot.

Seed 2: wipe $0.250 \to \mathbf{h}$ restore $0.969$; residual restore
$0.250$.
Figure~\ref{fig:causal} summarizes.

\section{Swap is necessity, not copy}

Swapping late $\mathbf{h}$ on write with the next example: acc $0.234$,
donor accuracy $0.072$ (chance $\approx 0.025$).
The intervention breaks the recipient bind; it does not transplant the
donor value.
This shows that $\mathbf{h}$ is required, not that $N$ is a linearly
swappable KV slot.

Key-matched patch of L17 $\mathbf{h}$ (same keys, different donor value):
still original V $0.984$, donor V $0.000$.
Patching donor $\mathbf{C}$ at query is the same negative.

ATR is more state-dependent than AR.
L17-only ATR-short wipe is $0.133$ (late-block $0.039$); L16/L18 stay

Restore L17 $\mathbf{h}$ on ATR-short: $0.945$; residual copy $0.039$ /

A local-only run is $0\%$ on AR and ATR.
Short conv / $D$-skip is not doing these tasks after this finetune.
That is the opposite of the pretrained-Mamba story in which AR often lives
in the conv \cite{mecheval2025}.
We are describing a learned state algorithm, not contradicting that
pretrained induction can be convolutional.

Multi-query AR (4 pairs, 2 queries): clean final-query $0.922$; L17
write-wipe $0.094$.
The second bind also lives in L17 $\mathbf{h}$.

\section{Two failures: pad versus stuffing}

OOD pad drops AR to $0.484$.
Clamping $\Delta \leftarrow 0$ on filler$\cup$pad at late layers, test
time, recovers $+0.219$ on seed 1.
The same clamp destroys stuffing (light $0.922 \to 0.328$; heavy
$0.578 \to 0.109$).
Seeds 2 and 3: pad clamp helps ($+0.078$ / $+0.266$); stuffing clamp hurts.
Sign is the result; do not lock $+0.22$ (Figure~\ref{fig:fail}).

Pad-only versus filler-only splits the old junk clamp exactly.
Zeroing $\mathbf{B}$ on fillers hurts; $\Delta=5$ on fillers $\to 0\%$.
Fillers are load-bearing; pads are overwrite.
L17 mean $\Delta$ is not a histogram smoking gun (pad $0.0049 <$ value
$0.0070$).
Effective rank of $\mathbf{h} \approx 1.05$ to $1.12$ on all splits;
correct versus wrong do not separate on norm / rank / $\Delta$.
We do not tell a rank-collapse story with these metrics.

\section{Content is distributed}

Single-$N$ channel wipes on L17 all stay $\approx 0.96$.
Wiping $k=2$ or $4$ of 16 slots stays clean; $k=8$ random $0.898$,
$k=8$ top-energy still $0.953$.
Energy ranking does not find the bind.

SVD of L17 $\mathbf{h}$ at last write: dropping the top singular value
does nothing ($0.961$); keeping only that component dies ($0.312$).
Rank-8 reconstruction is enough ($0.961$); dropping the top 8 singular
values matches L17 wipe ($0.297$).
Distributed in rank, not a 1-D code.

A Hidden-Attention-style control map
$\mathrm{mean}_E(\mathbf{h}_t \cdot \mathbf{C}_{\mathrm{query}})$ puts
softmax mass on keys ($0.444$), not the queried value ($0.111$)
\cite{ali2025,pitorro2025}.
Heatmaps do not locate this store.
Causal evidence is wipe/restore.

\section{Related work}

Hidden Attention reformulates the SSM as a linear token map
\cite{ali2025}; LaTIM decomposes latent interactions \cite{pitorro2025};
MambaLRP attributes along the scan \cite{jafari2024}.
We use a cheap $h \cdot C$ map as a control and then intervene on
$\mathbf{h}$.

Sharma et al.\ locate and edit factual associations in Mamba
\cite{sharma2024}.
Ensign and Garriga-Alonso find an IOI bottleneck at L39 in pretrained
370M \cite{ensign2024}.
We take the lesson that one layer can be a bottleneck.
Ours is L17 $\mathbf{h}$ on a finetuned 130M AR bind.
Factual remains $0\%$ after AR finetune; this is not a knowledge-editing
paper.

Wagh and Singh \cite{wagh2026} is the frozen-encoder companion:
pretrained 130M $\mathbf{h}$ is anisotropic; frozen probes collapse.
Finetune creates a usable store that is still not a linear letter at last
write.

Stuffed Mamba and LongMamba diagnose length as state interference
\cite{stuffed2024,longmamba2024}.
We split pad overwrite from stuffing and do not claim a stuffing fix.
Mechanistic eval finds pretrained Mamba often associating via short conv
\cite{mecheval2025}.
After AR FT, a local-only run is $0\%$ and L17 $\mathbf{h}$ wipe
kills the task.

\section{Limitations}

130M; synthetic AR/ATR; task-finetuned (pretrained 130M and 370M are
$0\%$ on these strings: scale does not unlock the bind); three FT seeds
for L17 wipe and pad sign, one paper checkpoint for the restore suite;
unfused sequential scan (VRAM is not the bottleneck; wall time is);
swap, key-matched state patch, and $C$-patch do not yield a portable
dictionary; pad recovery magnitude is seed-sensitive; stuffing has no
mechanism-aligned fix in this paper; no SAE, no IOI, no hybrid SSM, no
370M finetune.

A main-conference claim would need a pretrained-competent natural task
with the same L17-$\mathbf{h}$ story.
We do not have that.

\section{Conclusion}

When this Mamba does associative recall, the bind is in layer-17
recurrent state from the value token through query.
Residual-matched interventions miss it.
Probes at the query are readout.
Padding overwrites the store; stuffing is something else.
The code is distributed, not a slot you can swap.
Residual maps and implicit-attention heatmaps are neighbors; they are not
this result.
